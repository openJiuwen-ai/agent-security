# 仓库与安装

仓库根目录没有统一的安装入口。三个组件各有自己的 `pyproject`，在对应目录里安装。

---

## 1. 环境

三个组件都要求 Python 3.11 及以上。

| 组件 | 额外依赖 |
| --- | --- |
| Agent SSAS | HTTP 模式需要 fastapi、uvicorn、httpx。Windows、Linux、macOS 都可以跑 |
| JiuwenBox | Linux 上需要 bubblewrap。网络隔离还需要 iproute2、iptables、nftables |
| agent-shield | 运行时无第三方依赖。开发测试可选 tree-sitter，用于命令解析 |

## 2. 本地安装

在仓库根目录下分别进入组件目录。

Agent SSAS：

```bash
cd agent-ssas
uv venv
uv pip install -e .
uv pip install -e ".[http]"
```

JiuwenBox 的构建和启动命令写在 [jiuwenbox/README_CN.md](../../../jiuwenbox/README_CN.md)。策略样例在 `jiuwenbox/src/jiuwenbox/configs/`。

agent-shield：

```bash
cd agent_shield
pip install -e ".[dev]"
pytest
```
