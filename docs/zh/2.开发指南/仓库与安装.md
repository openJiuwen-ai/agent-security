# 仓库与安装

仓库根目录没有统一的安装入口。每个组件各有自己的 `pyproject.toml`，在对应目录里安装。五个组件都要求 Python 3.11 及以上，可以只装需要的部分。

---

## 1. 先确定要装哪些

| 你的需求 | 需要安装 | 额外准备 |
| --- | --- | --- |
| 在工具调用前做 allow / ask / deny | `agent-shield` | 无；命令解析依赖 tree-sitter，随包安装 |
| 拦截 Windows 文件、进程、网络访问 | `agent-shield` + `agent-security-dll` | Windows x64；DLL 防护需安装二进制包 |
| 把命令放进沙箱执行 | `jiuwenbox` | Linux 需要 bubblewrap；Windows 需要管理员完成账户、WFP、ACL 安装 |
| 观测 Agent 运行过程、做威胁检测 | `agent-ssas` | HTTP 模式另装 `[http]` |
| 加密保存 API Key、令牌等字段 | `security-gateway` | 无 |
| 对流式输出做脱敏 | `security-mask` | 无 |

## 2. 环境

| 组件 | 平台 | 运行时依赖 |
| --- | --- | --- |
| Agent SSAS | Windows / Linux / macOS | `PyYAML`；HTTP 模式另装 `[http]`（fastapi、uvicorn、httpx） |
| JiuwenBox | Linux；Windows x64 | pydantic、fastapi、uvicorn、httpx、mcp；Linux 需要 bubblewrap，网络隔离另需 iproute2、iptables、nftables |
| agent-shield | 跨平台；原生防护仅 Windows x64 | `PyYAML` 与 tree-sitter 四件套（bash / pwsh / batch 解析）；DLL 防护另装 `[dll-guard]` 与 `agent-security-dll` |
| Security Gateway | 跨平台 | `cryptography`、`PyYAML` |
| Security Mask | 跨平台 | 无第三方运行时依赖 |

JiuwenBox 的 Windows 运行时需要先用管理员权限完成账户、WFP 和 ACL 安装；环境未就绪时服务会启动失败，不会报告“启动成功但不可用”。具体步骤见 [JiuwenBox](JiuwenBox.md) 与 `jiuwenbox/README_CN.md`。

agent-shield 的 `process_guard.exe` 需要本机构建或安装 `agent-security-dll` 二进制包；DLL 防护还要求目标进程为 x64。

## 3. 本地安装

在仓库根目录下分别进入组件目录。

### Agent SSAS

```bash
cd agent_ssas
uv venv
uv pip install -e .
uv pip install -e ".[http]"
```

只做进程内检测时，可以不装 `[http]`。

### JiuwenBox

```bash
cd jiuwenbox
uv venv
uv sync
uv pip install -e .
```

构建 wheel、启动服务和 Windows 安装步骤写在 [jiuwenbox/README_CN.md](../../../jiuwenbox/README_CN.md)。策略样例在 `jiuwenbox/src/jiuwenbox/configs/`。

### agent-shield

```bash
cd agent_shield
pip install -e ".[dev]"
pytest
```

需要使用 Windows DLL 防护时，再安装二进制分发包：

```bash
pip install -e ".[dll-guard]"
pip install agent-security-dll
# 源码检出也可从本地安装：
# pip install ./native/windows-process-guard/python
```

### Security Gateway

```bash
cd security_gateway
pip install -e ".[dev]"
pytest tests -q
```

### Security Mask

```bash
cd foundation
pip install -e ".[dev]"
pytest
```

## 4. 安装后怎么验证

| 组件 | 验证方式 | 预期 |
| --- | --- | --- |
| Agent SSAS | `python -c "import agent_ssas"`；HTTP 模式再启动服务并访问 `/health` | 导入成功；服务返回健康状态 |
| JiuwenBox | 启动 `jiuwenbox-server` 后执行 `curl http://127.0.0.1:8321/health` | 返回 `status: ok` 和当前运行时 |
| agent-shield | `pytest` | 测试通过；DLL 防护用例在二进制缺失时会跳过 |
| Security Gateway | `pytest tests -q` | `tests/unit` 全部通过 |
| Security Mask | `pytest` | `test_stream_mask.py` 全部通过 |

JiuwenBox 的 `/api/v1/capabilities` 还会报告当前主机上哪些运行时可用；在 Windows 上建议先探测，再决定是否创建沙箱。
