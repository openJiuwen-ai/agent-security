# 开发指南

本指南说明仓库里各组件怎么安装，以及每个组件从哪份文档继续往下看。

## 1. 文档导航

| 你的目标 | 先读 | 内容 |
| --- | --- | --- |
| 先了解仓库整体能做什么 | [1.产品简介](../1.产品简介.md) | 五个组件各自解决什么问题，以及一次工具调用里的协作方式 |
| 把组件装到本机 | [仓库与安装](仓库与安装.md) | 目录、Python 版本、本地安装与安装后验证 |

## 2. 建议阅读顺序

1. 先读 [1.产品简介](../1.产品简介.md)，弄清五个组件各自解决什么问题。
2. 再读 [仓库与安装](仓库与安装.md)，装好需要的组件。
3. 然后进入对应组件页，了解它的输入、输出和最小用法。
4. 需要深入规则、协议或部署细节时，再读组件自己的 README、设计文档和 API 文档。
