# Agent Security

Agent Security 是 openJiuwen 的安全能力仓库。行为检测、隔离执行和进程内判定分属三个组件，放在同一棵目录里，各自安装、各自运行。

---

## 1. 组件

| 组件 | 目录 | 作用 |
| --- | --- | --- |
| Agent SSAS | `agent-ssas/` | 采集智能体运行时事件，做威胁检测，把结果写成 OCSF 日志 |
| JiuwenBox | `jiuwenbox/` | 沙箱服务。管理沙箱生命周期，按策略隔离命令和文件访问 |
| agent-shield | `agent_shield/` | 进程内 SDK。对工具调用给出 allow / ask / deny，并对进入模型的内容做检测 |

```text
agent-security/
├── agent-ssas/     态势感知
├── jiuwenbox/      沙箱服务
├── agent_shield/   进程内判定
└── docs/           本目录
```

## 2. 各自解决什么

Agent SSAS 看运行过程。它把生命周期事件送进检测引擎，产出风险评估和威胁日志。检测失败时主流程继续，这个设计叫 fail-open。

JiuwenBox 管执行环境。调用方通过 HTTP 服务创建沙箱、传文件、跑命令。隔离细节由策略文件决定。Linux 上服务用 bubblewrap 落地这套策略。

agent-shield 管单次判定。动作决策不访问网络，也不调用大模型。内容检测对文本给出风险信号，拦截与否由调用方决定。

三者没有合成一个进程。态势感知的详细教程在 `agent-ssas/docs/`，沙箱的安装和接口说明在 `jiuwenbox/README_CN.md`。
