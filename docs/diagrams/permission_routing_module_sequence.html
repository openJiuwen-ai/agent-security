PermissionEngine · 共享路由

按当前代码 db6f680 绘制：模块关系、构造注册、路由发现与调用

01 · 模块图：两层路由维度如何组合

关键结论：这里不是“两级分发”，也不是平铺工具名。第一层是安全对象类别，第二层只在 COMMAND 下补充命令方言；二者组合为一个 RouteContext，然后一次性匹配组件关注点。

02 · 构造与注册时序：注册点到底在哪里

注册点一句话：PermissionEngine._build_components() 返回组件集合；组件的 interests 是订阅声明，不是另一个注册中心。

03 · 路由发现 + 匹配 + 调用时序

01 当前接口行为：组件关注点未声明或为 None 时匹配所有路由；声明了关注点后按 RouteContext 筛选。组件不接收 route 时，使用两参数 evaluate(tool_name, tool_args)。这是当前代码允许的两种接口形式，不代表 01 存在历史组件或迁移过程。

04 · 组件接入契约

class ExampleComponent:
    interests = (
        RouteInterest(SecurityTarget.COMMAND,
                      CommandDialect.POSIX_SHELL),
        RouteInterest(SecurityTarget.COMMAND,
                      CommandDialect.POWERSHELL),
    )

    def configure(self, config): ...

    async def evaluate(self, tool_name, tool_args, route=None):
     ...

① 装配：实例加入 _build_components() 返回元组。

② 订阅：COMMAND 表示所有命令方言；加具体方言表示精确匹配。

③ 执行：匹配后接收同一个不可变 RouteContext，组件自行执行安全判断。

05 · 两级路由注册矩阵：可注册项穷举

注册格式：一级 SecurityTarget / 二级 CommandDialect。一级必须明确；二级可以是具体值，也可以用 None 表示通配。
一级路由（必选）二级注册值可注册形式含义
COMMAND
命令类		POSIX_SHELLCOMMAND / POSIX_SHELL只接收 POSIX Shell
POWERSHELLCOMMAND / POWERSHELL只接收 PowerShell
CMDCOMMAND / CMD只接收 Windows CMD
UNKNOWNCOMMAND / UNKNOWN只接收已确定为命令、但方言未知的调用
None（通配）COMMAND / *接收所有命令方言，包括 UNKNOWN
FILE
文件类		None（通配）FILE / *接收所有文件路由；文件没有命令方言
NETWORK
网络类		None（通配）NETWORK / *接收所有网络路由；网络没有命令方言
OTHER
当前代码的兜底类		None（通配）OTHER / *接收无法归类的调用；当前代码允许，但不属于三类业务主路由
ALL
仅订阅使用		None（通配）ALL / *接收全部类别与方言，包含 OTHER；不允许 ALL / 具体方言
上表穷举全部有意义的显式订阅：一级可以是具体类别，也可以显式写 ALL；二级的 * 只是图示，代码实际传 None，不传字符串 "*"。非 COMMAND 类指定命令方言会在注册构造时被拒绝。多个关注点取 OR，单个组件只调用一次。
三类业务主路由 + 一类兜底：OTHER 目前存在于 SecurityTarget 并可订阅；本次不调整它。
显式一级通配：RouteInterest(SecurityTarget.ALL) = ALL/*，匹配 COMMAND、FILE、NETWORK、OTHER 的所有解析结果。ALL 只用于组件订阅，resolve_route() 永远不会返回 ALL。
当前兼容行为：interests=None 仍然匹配全部路由；它是未声明订阅的兼容模式，不是正式的一级注册值。空元组 interests=() 不接收任何路由。
示例：RouteInterest(SecurityTarget.COMMAND) = COMMAND/*；RouteInterest(SecurityTarget.ALL) = ALL/*；RouteInterest(SecurityTarget.COMMAND, CommandDialect.UNKNOWN) 只匹配 UNKNOWN。
