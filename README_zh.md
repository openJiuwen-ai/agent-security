# Agent Security

[English](./README.md) | 简体中文

## 简介

**Agent Security** 是 openJiuwen 面向 Agent 场景的安全能力合集仓库，聚焦 Agent 行为检测、隔离运行、安全审计等方向，为 Agent 提供全链路的纵深安全防护。

当前仓库包含以下组件，后续将持续扩展更多安全能力：

- **JiuwenBox Sandbox**：轻量 Agent 安全沙箱服务，为 Agent 工具调用与代码执行提供分层隔离。
